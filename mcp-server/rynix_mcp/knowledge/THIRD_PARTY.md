# Third-party components

Rynix bundles technique guides and WSTG checklists derived from public security research.
Upstream licenses are respected; competitor product names are not used in Rynix-branded surfaces.

| Component | Role |
|-----------|------|
| OWASP WSTG | Web security test catalog |
| Public technique guides | Vulnerability class reference |
| Rust regex / walkdir | Static route extraction |

For optional template scanning, users provide their own `RYNIX_TEMPLATE_SCAN_BIN` binary.
